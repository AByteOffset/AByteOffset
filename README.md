<h3>ESAF — Endpoint Security Assurance Framework</h3>

<p>
<b>Read-only Windows endpoint security assurance and post-deployment verification framework for Microsoft security controls.</b>
</p>

<p>
ESAF is an Endpoint Security Assurance Framework built to independently verify that expected Windows security controls
are actually present and healthy on the endpoint rather than assuming successful policy deployment means effective enforcement.
Microsoft Defender and Intune remain the native management planes; ESAF independently observes selected effective local state.
</p>

<ul>
  <li>14 read-only endpoint security verification probes</li>
  <li>MDE onboarding and SENSE service health validation</li>
  <li>Defender AV, real-time protection, Network Protection, and Tamper Protection checks</li>
  <li>Firewall, BitLocker, TPM, Secure Boot, visible exclusions, and ASR inventory validation</li>
  <li>PASS / FAIL / REVIEW / PENDING assurance results</li>
  <li>Protected point-in-time evidence and assessment history for drift investigation</li>
  <li>Intune Win32 deployment in SYSTEM context with no permanent agent</li>
  <li>Optional Intune Custom Compliance integration for approved assurance use cases</li>
  <li>Read-only Microsoft policy intent reconciliation proof of concept</li>
  <li>Sanitized support-evidence export for authorized troubleshooting</li>
</ul>

<p>
  <a href="https://github.com/AByteOffset/endpoint-security-assurance-framework">Repository</a>
</p>

<h3>TraceAI Engine — Local-first AI SOC Investigation Platform</h3>

<p>
<b>AI-assisted SOC investigation, evidence correlation, triage, and human-reviewed reporting.</b>
</p>

<p>
TraceAI Engine is a local-first AI security investigation workspace for SOC workflows. It combines deterministic SOC logic,
Ollama-powered local LLM workflows, RAG-style case context retrieval, AI-assisted triage, evidence correlation,
interactive relationship graphs, MITRE ATT&CK mapping, KQL pivots, and Markdown/PDF incident reporting.
</p>

<ul>
  <li>Local LLM workflows using Ollama</li>
  <li>RAG-style SecOps Copilot over local case context and playbooks</li>
  <li>AI-assisted phishing and endpoint evidence triage</li>
  <li>Deterministic IOC and entity extraction</li>
  <li>Threat-intelligence enrichment workflows</li>
  <li>Interactive evidence relationship graph using PyVis / NetworkX</li>
  <li>MITRE ATT&CK mapping and KQL pivot generation</li>
  <li>Missing-evidence analysis for analyst validation</li>
  <li>Human-reviewed incident reports with guardrails</li>
  <li>Local-first design to reduce unnecessary exposure of sensitive investigation data</li>
</ul>

<h3>RiskWeaver AI — Agentic Cyber Risk Reduction Platform</h3>

<p>
<b>Local-first cyber risk prioritization, remediation planning, SLA tracking, and governance workflow platform.</b>

decisions. It combines vulnerability findings with asset criticality, exposure, attack paths, control gaps, business context,

<ul>
